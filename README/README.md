# Website Profil Pribadi

Ini adalah project website profil pribadi sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript.

## Fitur

- Navbar
- Smooth scroll
- Responsive design
- Card profile
- Form kontak
- Validasi form dengan JavaScript
- Dark mode
- Dark mode tersimpan dengan localStorage
- Footer
- Bagian project portfolio

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript

## Cara Menjalankan Project

1. Download atau clone project ini
2. Buka file `index.html` di browser
3. Website akan tampil secara lokal
